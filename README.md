# Clock Mobile UI (Next.js)

A mobile-first clock dashboard. On desktop it stays centered in a phone-width layout.


## Run locally
1. Install Node.js
2. Open this project folder in a terminal
3. Run `npm install`
4. Run `npm run dev`
5. Open http://localhost:3000


## Deploy
Push to GitHub and import the repo into Vercel. Framework preset: Next.js.
