# Clock UI — Next.js

A responsive dark widget dashboard inspired by the attached reference. Includes live local digital clock, analog clock, date widget, world clocks (Tokyo/London/New York), stopwatch, calendar navigation, timezone overview, and seconds progress.

## Run locally
1. Install Node.js LTS.
2. In this project folder run:
   ```bash
   npm install
   npm run dev
   ```
3. Open http://localhost:3000

## Deploy to Vercel
1. Push the project to a GitHub repository.
2. Go to https://vercel.com/new and import the repository.
3. Framework Preset: Next.js (auto-detected), Root Directory: `./`.
4. Click Deploy. No environment variables are required.

## Notes
The UI is intentionally based on the supplied screenshot's dark, dotted background, rounded widget cards, centered hero and responsive 6-column desktop grid.
