# Clock Mobile

Mobile-first clock dashboard built with Next.js and React.

## Pages / tabs
- Home: local time, analog clock, world clocks, stopwatch, daily thought
- Clock: local clock and expanded world clocks
- Timer: editable countdown timer and stopwatch
- Settings: theme toggle and 24-hour display preference

## Start locally
1. Install Node.js LTS.
2. In this folder, run `npm install`.
3. Run `npm run dev`.
4. Open http://localhost:3000.

The app is designed for mobile widths and can also be previewed on desktop.
